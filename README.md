Entry for the make.fun bounty [One-Liner Laugh Lab](https://make.fun/bounty/u-suroso-69-one-liner-laugh-lab-6ccf3aae): a single short funny line — the excuse a robot vacuum gives after eating a sock, told as a deadpan confession whose twist lands on the last words. The program writes the line to `entry.txt` in the output directory, after validating it against the gate (UTF-8, 1–200 characters, single line).

## Run it

```sh
python3 main.py
```
